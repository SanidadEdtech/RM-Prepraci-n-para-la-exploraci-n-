# Resonancia magnética: preparación para la exploración

Material didáctico sobre la preparación del paciente para una resonancia magnética.

> **EN** · Learning resource on preparing patients for an MRI scan.

🔗 **Demo:** [preparacionresonanciamagnetica.sanidadedtech.es](https://preparacionresonanciamagnetica.sanidadedtech.es/)

## Para quién es

Alumnado de T.S. en Imagen para el Diagnóstico y Medicina Nuclear.

## Qué incluye

- El paciente y la solicitud del estudio
- Seguridad: cribado y consentimiento
- Durante la exploración
- Casos prácticos

## Tecnología

- Página única en HTML, CSS y JavaScript, sin frameworks ni proceso de compilación.
- Diseño adaptable a móvil.
- Publicado con GitHub Pages.
- Desarrollado mediante *AI-driven prototyping*: diseño pedagógico y clínico propio, construcción asistida por IA y revisión manual.

## Uso

Abre la demo en el navegador o descarga `index.html` y ábrelo directamente: no necesita instalación.
